Rollwave

Rollwave est une application web qui référence les skateparks de France. Elle permet de les retrouver par ville, par code postal ou par adresse, de trouver ceux qui sont proches d'une position, et de partager des commentaires, des tricks et des vidéos.

Ce dépôt contient l'API REST (back-end Java / Spring Boot). Le front-end Angular est en cours de développement.
